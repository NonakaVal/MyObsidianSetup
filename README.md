
# Vault Structure

## Folder System

* **📂 <font color = 00bbfff>+</font>** — Anything that does not fit into the folders below

* **📂 <font color = 00bbfff>ATLAS</font>** — Study and literary notes

  * **00\_DRAFT** — Raw drafts of ideas and studies still in progress
  * **01\_INDEX** — Maps and indexes for navigating and interconnecting notes
  * **02\_CONCEPT** — Theoretical concepts, definitions, and explanatory models
  * **03\_RESOURCES** — Links, articles, books, PDFs, videos, and external materials
  * **04\_MAPS** — Mind maps and visual representations of topics

* **📂 <font color = 00bbfff>CALENDAR</font>** — Calendars and daily or periodic notes

  * **DAILY** — Daily notes, logs, tasks, and insights
  * **MONTHLY** — Monthly planning and reflections
  * **WEEKLY** — Weekly planning and review
  * **YEARLY** — Annual reviews and goals

* **📂 <font color = 00bbfff>CODE</font>** —

  * **05\_SNIPPETS** — Reusable code snippets and practical examples
  * **06\_COMPONENT** — Reusable blocks, functions, algorithms, and patterns
  * **07\_DOC** — Explanatory documentation or tutorials
  * **08\_WORKFLOW** — Step-by-step practical processes or pipelines

* **📂 <font color = 00bbfff>EFFORTS</font>** — Guidance for active efforts and projects

  * **09\_AREAS** — Continuous focus areas (health, finance, career, etc.)
  * **10\_PROJECTS** — Projects with a defined start, middle, and end
  * **11\_ARCHIVES** — Completed or paused projects
  * **12\_RESOURCES** — Supporting materials and specific project references
  * **13\_WORKSTATION** — Operational daily notes and execution records

* **📂 <font color = #00bbff>SELF</font>** — Self-knowledge, experiences, and personal growth

  * **14\_FAITH** — Texts on faith, spirituality, or personal beliefs
  * **15\_FAVS** — People, moments, places, or things you love, like an emotional chest
  * **16\_GROWTH** — Personal development, habits, therapy, boundaries, learnings, and evolution
  * **17\_HEALTH** — Physical and mental health: nutrition, sleep, crises, logs, and self-care
  * **18\_MEMOS** — Letters to yourself, meaningful phrases, private writings
  * **19\_PHILOSOPHY** — Worldviews, values, spirituality, and existential texts
  * **20\_SOCIAL** — Notes on people, contacts, networks, or important profiles

  - **21\_MUSIC** — Music, playlists, favorite artists, and musical studies

* **📂 <font color = 00bbfff>SKETCH</font>** — Loose drafts and uncategorized notes

* **📂 <font color = 00bbfff>SYSTEM</font>** — Organizational system and infrastructure

  * **ASSETS** — Templates, icons, images, styles, and visual components
  * **SCRIPTS** — Scripts and automation
  * **MEDIA** — Repository of multimedia files used in notes
  * **TEMPLATE** — My templates

# Main Note Properties

> `tag`, `Hubs`, and `connections`

### TAG

* Classifies the TYPE or PURPOSE of a note; also used for TASK management

```
`learning` - study notes
`resources` - tools or lists of external materials
`tocomplete` - incomplete notes
`reading` - notes on books
`lab` - planning, reports, projects, and ideas
`calendar` - calendar-based planning notes and daily notes
`walkthrough` - step-by-step MOCs
`dataview` - dataview notes
`dashboard`
`snipet`
`workflow`
`draft`
...
```

# Naming Conventions

### Atlas

* `draft-[topic]-[description]` → e.g., `draft-math-initial-sets`
* `index-[topic]-[map-type]` → e.g., `index-python-concept-map`
* `concept-[topic]-[theoretical-description]` → e.g., `concept-statistics-normal-distribution`
* `snip-[library]-[action]-[description]` → e.g., `snip-seaborn-plot-bar-chart`
* `cmp-[domain]-[action]-[description]` → e.g., `cmp-string-utils-remove-accents`
* `doc-[tool]-[module/method]-[description]` → e.g., `doc-pandas-merge-table-combination`
* `flow-[type]-[short-description]` → e.g., `flow-datascience-data-cleaning`
* `res-[type]-[source]-[description]` → e.g., `res-pdf-article-random-forest`
* `map-[topic]-[representation-type]` → e.g., `map-ml-deep-learning-visual`

### Calendar

* `YYYY-MM-DD` → e.g., `2025-05-11`
* `YYYY-[W]ww` → e.g., `2025-W19`
* `YYYY-MM` → e.g., `2025-05`
* `YYYY` → e.g., `2025`

### Drafts

* `note-[topic]-[brief-description]` → e.g., `note-ai-ethics-daily-use`

### Efforts

* `project-[name]-[start-date]-[end-date]` → e.g., `project-app-organizer-2025-01-01-2025-06-30`
* `area-[domain]-[description]` → e.g., `area-finance-personal-control`
* `res-proj-[name]-[material-type]` → e.g., `res-proj-data-course-slides`
* `wrk-[context]-[action/description]` → e.g., `wrk-ecommerce-shipping-process`
* `archive-[project-name]-[year]` → e.g., `archive-site-restructure-2024`

### Entertainment

* `ent-music-[artist]-[description]` → e.g., `ent-music-ludovico-einaudi-calm-playlist`

### Social

* `soc-people-[name]-[context]` → e.g., `soc-people-carlos-linkedin-network`
* `soc-thinking-[topic]-[reflection]` → e.g., `soc-thinking-creative-authenticity`

### System

* `asset-[type]-[description]` → e.g., `asset-folder-icon-gaming`
* `media-[type]-[description]` → e.g., `media-video-tutorial-git`
* `template-[type]-[usage]` → e.g., `template-project-scientific-research`
