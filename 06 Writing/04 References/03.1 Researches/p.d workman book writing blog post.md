# The 5 templates

- Snowflake Method – outlines the snowflake method, includes callouts for the logline, summary, etc.
- Character Sheet – name, picture, motive, conflict, etc. and a section for the character to introduce himself in his own voice
- Tabular Summary – yaml properties in a table so I can easily follow which scenes characters were in, setting, timeline, etc., as well as sections for notes, tasks, and draft control
- To Do list – for tracking tasks to be done at each stage of writing – global tasks, queries for open and finished checkboxes, tasks to be completed before finalizing the book
