[[Manifesto obsidian]]

- **A Filosofia Local-First**
    - Arquivos Markdown (.md) como texto puro e legível por qualquer software.
    - Independência de nuvem: seus dados permanecem no seu hardware, não em servidores de terceiros.
        Evitar o "Vendor Lock-in": facilidade de migração para VS Code ou outros editores no futuro.
        
- **Organização Escalável (ACE & Folders)**
    - Priorização de links e conexões em vez de uma hierarquia rígida de pastas.
    - Estrutura sugerida: Atlas (Conhecimento), Calendar (Tempo) e Efforts (Projetos).
    - Uso de pastas de "Suporte" ou "Assets" para manter o diretório raiz limpo.
- **Recursos Nativos Essenciais (Otimização)**
    
    - Ativação de Backlinks para descoberta de conexões indiretas.
        
    - Notas Diárias como hub central de contexto (links para datas vs. metadados estáticos).
        
    - Domínio da Paleta de Comandos (Ctrl+P) e comandos fixados para velocidade.
        
- **Configurações de Usabilidade "Future Proof"**
    
    - Padronização de Hotkeys para navegação rápida (retrair menus, abrir notas específicas).
        
    - Ajuste de fonte (Ctrl+Scroll) para legibilidade imediata em diferentes telas.
        
    - Portabilidade de configurações: o arquivo `.obsidian` como o "DNA" do seu fluxo de trabalho.
        
- **Dicas Técnicas e Performance**
    
    - Uso de `Rebuild Vault Cache` para resolver inconsistências de indexação.
        
    - Buscas embutidas (Query) em vez de plugins pesados para listar tarefas.
        
    - Snippet de CSS para personalização visual sem depender de temas complexos.
        
- **O Teste de Fogo do Plugin**
    
    - Avaliação constante: "Se eu desativar todos os plugins, minha nota ainda faz sentido?".
        
    - Uso ético de extensões: plugins devem facilitar a escrita, não ditar o formato do dado.
        
- **Fechamento e CTA**
    
    - Obsidian como um ecossistema de ideias a longo prazo.
        
    - Foco em estudantes de tecnologia e profissionais de conhecimento.
